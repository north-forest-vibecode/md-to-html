> Лёгкий конвертер Markdown → HTML на чистом Python. Без `pip install`, без зависимостей, без сборки. Кладёшь скрипт рядом с `.md` файлами — получаешь аккуратный HTML со встроенными стилями и кликабельным оглавлением.

Проект работает по принципу **«всё в одной папке»**: скрипт сканирует директорию, в которой лежит сам, показывает нумерованный список `.md` файлов и конвертирует выбранный в готовый к просмотру HTML-документ.

## Возможности

- **Нулевые зависимости** — только стандартная библиотека Python (`os`, `sys`, `re`).
- **Один файл** — весь код в `converter.py`, ничего устанавливать не нужно.
- **Интерактивный выбор** — нумерованный список `.md` файлов прямо в консоли.
- **Современный минимализм** — встроенный CSS: карточка на светлом фоне, типографика, тёмные блоки кода, зебра-таблицы.
- **Автооглавление** — раздел «Содержание» автоматически превращается в список рабочих якорных ссылок.
- **Якоря у заголовков** — каждый `h1`–`h6` получает `id`, можно ссылаться из любого места документа.
- **Безопасный вывод** — HTML в исходнике экранируется, свои теги не ломаются.
- **Устойчивость к мусору** — BOM, CRLF, случайно скопированная обёртка ```` ```markdown ```` обрабатываются автоматически.
- **Самодиагностика** — после конвертации скрипт сам сообщает, сколько якорей и ссылок создано.
- **Кроссплатформенность** — Windows, Linux, macOS.

## Быстрый старт

**1. Клонируй репозиторий:**

```bash
git clone https://github.com/north-forest-vibecode/md-to-html.git
cd md-to-html
```

**2. Положи свои `.md` файлы в папку со скриптом:**

```
md-to-html/
├── md_to_html.py
├── my-notes.md
└── documentation.md
```

**3. Запусти:**

```bash
python md_to_html.py
```

На Windows также работает `py md_to_html.py` или обычный двойной клик по файлу.

**4. Введи номер файла** — рядом появится `my-notes.html`. Открывай в браузере.

## Поддерживаемый синтаксис

| Markdown | Результат |
|---|---|
| `# … ######` | `<h1>` … `<h6>` с атрибутом `id` |
| `**текст**`, `__текст__` | `<strong>` |
| `*текст*`, `_текст_` | `<em>` |
| `~~текст~~` | `<del>` |
| `` `код` `` | `<code>` |
| ` ``` ` … ` ``` ` | `<pre><code>` |
| `- пункт`, `* пункт` | `<ul><li>` |
| `1. пункт` | `<ol><li>` |
| `> цитата` | `<blockquote>` |
| `---`, `***`, `___` | `<hr>` |
| `[текст](url)` | `<a href>` |
| `![alt](url)` | `<img>` |
| `\| ячейка \| ячейка \|` | `<table>` |
| Раздел «Содержание» | автосписок якорных ссылок |

## Оглавление и навигация

Достаточно завести в документе раздел с любым из названий:

```markdown
## Содержание
```

Также распознаются: `## Оглавление`, `## Contents`, `## Table of Contents`.

Скрипт найдёт его и **сам построит кликабельный список** из всех заголовков второго уровня (`##`). Что бы ни было написано под этим заголовком — список, абзацы или пустота — оно будет заменено рабочим оглавлением.

Правила генерации якорей:

- Текст заголовка приводится к нижнему регистру, пробелы заменяются на дефисы.
- Эмодзи и спецсимволы из `id` вырезаются, но **в самом тексте заголовка сохраняются**.
- Кириллица поддерживается: `## Быстрый старт` → `id="быстрый-старт"`.
- Одинаковые заголовки получают уникальные суффиксы: `-2`, `-3` и т. д.

Дополнительно: любой пункт списка, текст которого совпадает с заголовком, автоматически становится ссылкой на него.

## Ограничения

Проект намеренно простой, поэтому ряд возможностей GFM не реализован:

- Вложенные списки не поддерживаются — все списки плоские.
- Чек-листы `- [x]` отображаются как обычный текст внутри пункта.
- Выравнивание колонок в таблицах (`:---:`) игнорируется.
- Подсветка синтаксиса в блоках кода отсутствует (язык после ` ``` ` не учитывается).
- Сырой HTML внутри Markdown экранируется — вставки вроде `<div>` не пройдут.
- Сноски, математика, диаграммы не поддерживаются.

## Как это работает

| Функция | Назначение |
|---|---|
| `get_script_dir()` | определяет папку, где лежит скрипт |
| `find_md_files()` | собирает и сортирует `.md` файлы |
| `normalize_source()` | убирает BOM, CRLF и внешнюю обёртку кода |
| `make_slug()` | превращает текст заголовка в `id`-якорь |
| `process_inline()` | инлайновая разметка через защищённые плейсхолдеры |
| `convert_md_to_html()` | построчный разбор блоков + автооглавление |
| `generate_html()` | сборка документа со встроенным CSS |
| `main()` | интерфейс, ввод-вывод, диагностика |

Конвертация выполняется в два прохода: сначала собираются все заголовки и их `id`, затем строится HTML — благодаря этому оглавление знает обо всех разделах, даже о тех, что идут ниже.

## Диагностика

После каждой конвертации скрипт печатает отчёт:

```text
--- ДИАГНОСТИКА ---
Заголовков с якорями:  14
Ссылок для перехода:   5
Навигация сгенерирована корректно.
-------------------
```

- `Заголовков с якорями: 0` — в файле нет строк вида `# Текст`.
- `Ссылок для перехода: 0` при ненулевых якорях — не найден раздел «Содержание».
- Оба числа больше нуля — навигация собрана, открывай файл по пути из последней строки.

## Частые проблемы

**Решётка `#` видна в HTML, заголовок не жирный.**
В начале файла был BOM — невидимая метка кодировки. Исправлено: чтение идёт в `utf-8-sig`. Обнови скрипт до актуальной версии.

**Кликаю по содержанию — ничего не происходит.**
Проверь блок диагностики. Если ссылки созданы, значит открыта старая вкладка со старой версией HTML — открой свежий файл по пути из консоли.

**Весь документ превратился в один серый блок кода.**
Ты скопировал текст вместе с внешней обёрткой ```` ```markdown ````. Скрипт снимает её автоматически, но проверь, что в начале файла нет лишних строк.

**Символы `<`, `>`, `&` отображаются как текст.**
Так и задумано: сырой HTML экранируется ради безопасности.
