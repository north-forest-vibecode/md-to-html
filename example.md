## ✨ Возможности

* **Простота** — пишется в любом текстовом редакторе.
* **Кроссплатформенность** — открывается везде без потери структуры.
* **Гибкость** — легко конвертируется в HTML, PDF или Word.

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта:
   ```bash
   cd project-name
   ```
3. Откройте файл в редакторе (например, [VS Code](https://htmlacademy.ru/blog/git/markdown) или [Obsidian](https://kokoc.com/blog/markdown/)).

## 🎨 Синтаксис и примеры

### Заголовки
# Заголовок H1
## Заголовок H2
### Заголовок H3

### Форматирование текста
* *Курсив* или _курсив_
* **Жирный** или __жирный__
* ~~Зачеркнутый текст~~
* `Встроенный код`

### Списки
Маркированный список:
* Элемент первого уровня
  * Вложенный элемент (отступ в 4 пробела)
* Еще один пункт

Нумерованный список:
1. Первый шаг
2. Второй шаг
3. Третий шаг
